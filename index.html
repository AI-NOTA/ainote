AINOTA 개인정보처리방침

개발자 YICA · 시행일 2026년 9월 2일

YICA(이하 “개발자”)는 AINOTA(이하 “앱”) 이용자의 개인정보를 중요하게 생각하며, 관련 법령 및 Google Play 정책에 따라 앱이 접근하거나 처리하는 정보와 그 이용 목적을 다음과 같이 안내합니다.

1. 개인정보 처리 원칙

AINOTA는 회의, 대화, 일정 및 메모를 사용자의 기기에서 관리하고, 사용자가 선택한 경우 AI를 이용하여 대화 내용을 정리하거나 요약하는 기능을 제공합니다.

앱은 기능 제공에 필요한 범위에서만 사용자 데이터에 접근하며, 광고 판매 또는 사용자 추적을 목적으로 개인정보를 수집하거나 판매하지 않습니다.

2. 앱이 접근하거나 처리하는 정보

마이크 및 음성인식
사용자가 음성 입력 기능을 직접 실행한 경우 음성을 텍스트로 변환하기 위해 기기의 마이크 권한을 사용할 수 있습니다. 마이크는 사용자가 음성 입력 기능을 사용하는 동안 해당 기능 제공을 위해 사용됩니다. 음성 입력 기능은 Android 기기에 설정된 시스템 음성인식 서비스를 이용하며, 기기 및 음성인식 서비스의 설정에 따라 음성 데이터가 해당 음성인식 서비스 제공자의 서버에서 처리될 수 있습니다. 이 경우 해당 서비스 제공자의 개인정보처리방침이 적용될 수 있습니다.

기기 캘린더
사용자가 캘린더 접근을 허용한 경우 일정 표시 및 캘린더 관련 기능을 제공하기 위해 기기의 캘린더 정보에 접근할 수 있습니다. 접근할 수 있는 정보에는 일정 제목, 날짜, 종일 여부 및 캘린더 이름 등이 포함될 수 있습니다. 캘린더에서 읽은 정보는 해당 기능 제공을 위해 기기 내에서 처리되며 AI 요약을 목적으로 Groq에 전송하지 않습니다.

알림 정보
사용자가 Android의 알림 접근 권한을 직접 허용한 경우 AINOTA는 새롭게 발생하는 메신저 등의 알림에서 발신자 및 알림 내용을 읽을 수 있습니다. 해당 정보는 새로운 알림에서 일정과 관련된 내용을 탐지하고 사용자의 일정 관리를 보조하기 위한 목적으로 기기 내에서 처리됩니다. AINOTA는 이 기능을 이용하여 과거에 저장된 SMS 또는 메신저 대화 기록을 직접 읽지 않습니다. 알림 접근 기능으로 읽은 메신저 알림 내용은 AI 분석을 위해 Groq로 전송하지 않습니다. 알림 접근 권한은 사용자가 Android 시스템 설정에서 언제든지 해제할 수 있습니다.

사용자가 직접 입력하거나 공유한 내용
사용자가 AINOTA에 직접 작성하거나 Android 공유 기능 등을 통해 전달한 텍스트, 대화 또는 문서 내용은 회의록 작성, 메모 및 관련 기능 제공을 위해 처리될 수 있습니다. 사용자가 AI 요약 기능을 실행하는 경우 해당 내용의 전부 또는 일부가 AI 처리를 위해 외부 AI 서비스 제공자에게 전송될 수 있습니다.

3. AI 기능 및 외부 서비스 전송

AINOTA는 AI 요약 기능을 제공하기 위해 Groq의 API 서비스를 사용할 수 있습니다.

사용자가 AI 요약 기능을 실행하는 경우 사용자가 직접 입력하거나 공유한 대화 및 음성 인식 결과 등의 내용이 AI 처리를 위해 Groq에 전송될 수 있습니다.

AINOTA의 알림 접근 기능을 통해 자동으로 읽은 메신저 알림 내용과 기기 캘린더에서 읽은 정보는 AI 요약을 위해 Groq에 전송하지 않습니다.

AI 서비스 이용 시 전송된 데이터의 처리에는 해당 외부 서비스 제공자의 정책이 적용될 수 있습니다.

4. Groq API 키

AINOTA의 AI 기능은 사용자가 직접 발급받은 Groq API 키를 입력하여 사용하는 방식입니다.

입력된 API 키는 사용자의 Android 기기에 저장되며 Android Keystore를 이용한 암호화 방식으로 보호됩니다.

Groq API 키는 AINOTA의 사용자 백업 데이터에 포함되지 않습니다.

사용자는 앱 설정에서 API 키를 변경하거나 삭제할 수 있습니다.

5. 데이터 저장 및 보관

회의록, 일정, 퀵노트 및 앱 설정 등의 데이터는 기본적으로 사용자의 기기에 저장됩니다.

앱 기능 수행 과정에서 생성되는 일부 임시 데이터는 필요한 처리 완료 후 삭제되거나 제한적으로 보관될 수 있습니다.

AI 사용량 및 최근 AI 요청 정보는 앱 내 사용량 확인 기능을 제공하기 위해 기기에 저장될 수 있으며, 사용자는 앱 설정에서 누적 사용량 정보를 초기화할 수 있습니다.

6. 백업

AINOTA는 사용자가 직접 실행하는 백업 및 복원 기능을 제공할 수 있습니다.

보안을 위해 Groq API 키 및 앱 잠금 PIN과 같은 인증·보안 정보는 AINOTA의 사용자 백업 데이터에 포함하지 않습니다.

Android 시스템의 자동 백업 또는 기기 이전 기능에서도 앱이 지정한 민감한 보안 정보 및 임시 알림 데이터가 제외되도록 구성합니다.

7. 개인정보의 제3자 제공 및 공유

개발자는 이용자의 개인정보를 광고 판매 또는 사용자 추적 목적으로 제3자에게 판매하지 않습니다.

다만 사용자가 AI 요약 기능을 직접 사용하는 경우 해당 기능 제공에 필요한 내용이 AI 처리 서비스 제공자인 Groq에 전송될 수 있습니다.

이러한 전송은 사용자가 요청한 AI 기능을 제공하기 위한 목적으로 제한됩니다.

8. 데이터 전송 및 보안

AINOTA는 외부 AI 서비스와 통신할 때 HTTPS 등 암호화된 네트워크 연결을 사용합니다.

앱은 평문 HTTP 통신을 허용하지 않도록 구성하며, Groq API 키 등 중요한 인증 정보는 기기에서 암호화하여 저장합니다.

9. 권한 선택 및 철회

마이크, 캘린더 및 알림 접근과 같은 권한은 해당 기능을 사용하기 위해 필요한 경우 사용자에게 요청됩니다.

사용자는 권한 요청을 거부하거나 Android 시스템 설정에서 이미 허용한 권한을 철회할 수 있습니다.

특정 권한을 허용하지 않더라도 해당 권한이 필요하지 않은 AINOTA의 다른 기능은 계속 사용할 수 있습니다.

10. 데이터 삭제

사용자는 앱에서 저장한 회의록, 일정 및 기타 지원되는 데이터를 직접 삭제할 수 있습니다.

앱에서 제공하는 전체 초기화 기능을 사용하는 경우 기기에 저장된 AINOTA 데이터와 앱의 보안 저장소에 저장된 관련 정보가 삭제됩니다.

앱을 삭제하면 Android가 관리하는 앱 전용 저장공간의 데이터도 함께 삭제됩니다. 다만 사용자가 별도로 내보내거나 백업한 파일은 사용자가 직접 삭제해야 합니다.

11. 어린이의 개인정보

AINOTA는 어린이를 대상으로 설계된 서비스가 아니며, 개발자는 앱의 기능을 통해 어린이의 개인정보를 의도적으로 수집하는 것을 목적으로 하지 않습니다.

12. 개인정보처리방침 변경

앱 기능, 관련 법령 또는 정책의 변경에 따라 본 개인정보처리방침이 변경될 수 있습니다.

중요한 변경사항이 있는 경우 앱 또는 개인정보처리방침이 게시된 페이지를 통해 안내할 수 있습니다.
