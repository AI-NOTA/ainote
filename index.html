AINOTA 개인정보처리방침

운영자 주식회사 씨비전 (SEEVISION CO., LTD.) · 시행일 2026년 9월 17일

주식회사 씨비전(이하 “회사”)은 AINOTA(이하 “앱”) 이용자의 개인정보를 중요하게 생각하며, 관련 법령 및 Google Play 정책에 따라 앱이 접근하거나 처리하는 정보와 그 이용 목적을 다음과 같이 안내합니다.

1. 개인정보 처리 원칙

AINOTA는 회의록, 일정, 퀵노트 및 메신저에서 인식한 일정 관련 정보를 사용자의 기기에서 관리하고, 사용자가 선택한 경우 AI를 이용하여 사용자가 직접 입력하거나 공유한 내용을 정리하거나 요약하는 기능을 제공합니다.

앱은 기능 제공에 필요한 범위에서만 사용자 데이터에 접근하며, 광고 판매 또는 사용자 추적을 목적으로 개인정보를 판매하지 않습니다.

2. 앱이 접근하거나 처리하는 정보

마이크
사용자가 AINOTA 또는 PC Web에서 음성녹음·음성 입력 기능을 직접 실행한 경우 음성을 처리하기 위해 기기의 마이크 권한을 사용할 수 있습니다. 앱 최초 실행만으로 마이크 권한을 요청하지 않으며, 해당 기능을 사용할 때 필요한 권한을 요청합니다. PC Web에서 휴대폰 마이크 권한이 필요한 경우 휴대폰 AINOTA에서 Android 권한 요청을 표시할 수 있습니다.

기기 캘린더
사용자가 캘린더 읽기 권한을 허용한 경우 AINOTA 캘린더에 공휴일 및 대체공휴일을 정확하게 표시하기 위한 목적으로 기기 캘린더 정보를 읽을 수 있습니다. AINOTA는 기기 캘린더에 일정을 추가하거나 수정하기 위한 쓰기 권한을 사용하지 않습니다. 캘린더에서 읽은 정보는 해당 기능 제공을 위해 처리되며 AI 요약을 목적으로 Groq에 전송하지 않습니다.

메신저 알림 정보
사용자가 Android의 알림 접근 권한을 직접 허용하고 AINOTA의 메신저 일정 관리 기능을 활성화한 경우, 새롭게 발생하는 메신저 등의 알림에서 발신자 및 알림 내용을 읽어 일정 관련 내용을 탐지하고 일정 관리를 보조할 수 있습니다. 메신저 일정 관리 기능을 끄면 해당 기능을 위한 신규 알림의 수집·일정 처리를 수행하지 않습니다. AINOTA는 이 기능을 이용하여 과거에 저장된 SMS 또는 메신저 대화 기록을 직접 읽지 않으며, 알림 접근 기능으로 읽은 SMS, 카카오톡, 알림톡 및 기타 메신저 알림 내용을 AI 분석을 위해 Groq에 전송하지 않습니다.

알림 권한
오늘의 헤드라인 및 일정 관련 알림 등 AINOTA의 주요 알림을 표시하기 위해 Android 알림 권한을 사용할 수 있습니다. 알림을 허용하지 않아도 알림이 필요하지 않은 다른 기능은 사용할 수 있습니다.

사용자가 직접 입력하거나 공유한 내용
사용자가 AINOTA에 직접 작성하거나 Android 공유 기능 등을 통해 전달한 텍스트, 대화 또는 문서 내용은 회의록 작성, 메모 및 관련 기능 제공을 위해 처리될 수 있습니다. 사용자가 AI 요약 기능을 실행하는 경우 해당 내용의 전부 또는 일부가 AI 처리를 위해 외부 AI 서비스 제공자에게 전송될 수 있습니다.

3. AI 기능 및 외부 서비스 전송

AINOTA는 AI 요약 기능을 제공하기 위해 Groq의 API 서비스를 사용할 수 있습니다.

사용자가 AI 요약 기능을 직접 실행하는 경우 사용자가 직접 입력하거나 공유한 대화 및 음성 인식 결과 등의 내용이 AI 처리를 위해 Groq에 전송될 수 있습니다.

AINOTA의 알림 접근 기능을 통해 자동으로 읽은 메신저 알림 내용과 기기 캘린더에서 읽은 정보는 AI 요약을 위해 Groq에 전송하지 않습니다.

AI 서비스 이용 시 전송된 데이터의 처리에는 해당 외부 서비스 제공자의 정책이 적용될 수 있습니다.

4. Groq API 키

AINOTA의 AI 기능은 사용자가 직접 발급받은 Groq API 키를 입력하여 사용하는 방식입니다.

입력된 API 키는 사용자의 Android 기기에 저장되며 Android Keystore를 이용한 암호화 방식으로 보호됩니다.

Groq API 키는 AINOTA의 사용자 백업 데이터에 포함되지 않습니다. 사용자는 앱 설정에서 API 키를 변경하거나 삭제할 수 있습니다.

5. PC 연결 및 로컬 네트워크

사용자가 PC 연결 기능을 켠 경우 AINOTA는 같은 로컬 네트워크에 있는 AINOTA PC Link를 찾고 PC Web과 연결하기 위해 로컬 네트워크 통신을 사용합니다.

PC 연결에는 사용자의 확인을 거치는 페어링 절차가 적용되며, 연결된 PC Web에서는 AINOTA가 제공하는 범위에서 일정·회의록 등의 데이터를 조회하거나 백업·복원하고 휴대폰 마이크를 사용하는 음성 기능을 실행할 수 있습니다.

PC Web 연결은 같은 로컬 네트워크에서 동작하는 기능이며 인터넷상의 공개 웹 서비스로 제공되는 기능이 아닙니다. 외부 AI 서비스와의 통신에는 별도의 암호화된 HTTPS 연결을 사용합니다.

6. 데이터 저장 및 보관

회의록, 일정, 퀵노트, 메신저 일정 관리 데이터 및 앱 설정 등의 데이터는 기본적으로 사용자의 기기에 저장됩니다.

앱 기능 수행 과정에서 생성되는 일부 임시 데이터는 필요한 처리 완료 후 삭제되거나 제한적으로 보관될 수 있습니다.

AI 사용량 및 최근 AI 요청 정보는 앱 내 사용량 확인 기능을 제공하기 위해 기기에 저장될 수 있으며, 사용자는 앱 설정에서 누적 사용량 정보를 초기화할 수 있습니다.

7. 백업 및 복원

AINOTA는 사용자가 직접 실행하는 백업 및 복원 기능을 제공하며, PC Web에서도 사용자의 명시적인 조작으로 백업 파일을 생성하거나 백업 파일에서 데이터를 복원할 수 있습니다.

보안을 위해 Groq API 키 및 앱 잠금 PIN과 같은 인증·보안 정보는 AINOTA의 사용자 백업 데이터에 포함하지 않습니다.

AINOTA는 Android 운영체제의 앱 자동 백업·자동 복원 기능을 사용하지 않습니다. 앱을 삭제한 뒤 다시 설치하면 AINOTA가 별도로 내보낸 백업 파일을 사용자가 직접 복원하지 않는 한 기존 AINOTA 사용자 데이터가 자동으로 복원되지 않습니다.

사용자가 기기 외부에 별도로 저장하거나 내보낸 백업 파일은 AINOTA의 전체 초기화 또는 앱 삭제로 자동 삭제되지 않으며 사용자가 직접 관리해야 합니다.

8. 개인정보의 제3자 제공 및 공유

회사는 이용자의 개인정보를 광고 판매 또는 사용자 추적 목적으로 제3자에게 판매하지 않습니다.

다만 사용자가 AI 요약 기능을 직접 사용하는 경우 해당 기능 제공에 필요한 내용이 AI 처리 서비스 제공자인 Groq에 전송될 수 있습니다. 이러한 전송은 사용자가 요청한 AI 기능을 제공하기 위한 목적으로 제한됩니다.

9. 데이터 전송 및 보안

AINOTA는 Groq 등 외부 AI 서비스와 통신할 때 HTTPS 등 암호화된 네트워크 연결을 사용합니다. Groq API 키 등 중요한 인증 정보는 기기에서 보호하여 저장합니다.

PC Web은 사용자가 활성화한 동일 로컬 네트워크 연결을 이용하며, 페어링과 세션 인증 절차를 통해 접근을 제한합니다. 동일 로컬 네트워크 자체의 안전성은 사용자가 사용하는 네트워크 환경의 영향을 받을 수 있습니다.

10. 권한 선택 및 철회

마이크, 캘린더 읽기, 알림, 알림 접근 및 로컬 네트워크 접근 등은 해당 기능 제공에 필요한 범위에서 사용됩니다.

사용자는 Android에서 지원하는 범위 내에서 권한 요청을 거부하거나 이미 허용한 권한을 시스템 설정에서 철회할 수 있습니다. 특정 권한을 허용하지 않더라도 해당 권한이 필요하지 않은 AINOTA의 다른 기능은 계속 사용할 수 있습니다.

11. 데이터 삭제 및 전체 초기화

사용자는 앱에서 저장한 회의록, 일정 및 기타 지원되는 데이터를 직접 삭제할 수 있습니다.

AINOTA의 전체 초기화를 실행하면 앱이 관리하는 일정, 회의록, 메신저 관련 데이터, 앱 설정 및 관련 보안 저장 정보 등 AINOTA 사용자 데이터가 삭제되고 초기 상태로 돌아갑니다.

Android 운영체제가 관리하는 앱 권한 허용 상태는 AINOTA의 전체 초기화만으로 변경되지 않을 수 있습니다.

앱을 삭제하면 Android가 관리하는 앱 전용 저장공간의 데이터도 함께 삭제됩니다. 다만 사용자가 별도로 내보내거나 저장한 백업 파일은 사용자가 직접 삭제해야 합니다.

12. 구독 및 결제

AINOTA의 유료 구독이 제공되는 경우 결제는 Google Play 결제 시스템을 통해 처리됩니다. AINOTA는 사용자의 결제카드 번호 등 Google Play가 직접 처리하는 결제수단 정보를 직접 수집하거나 저장하지 않습니다.

구독 가격, 무료 체험 기간, 자동 갱신 조건 등 실제 결제 조건은 구매 시 Google Play에 표시되는 내용을 기준으로 하며, 구독의 관리 및 취소는 Google Play에서 할 수 있습니다.

결제 취소 및 환불은 Google Play 정책 및 관련 법령에 따라 처리됩니다.

13. 어린이의 개인정보

AINOTA는 어린이를 대상으로 설계된 서비스가 아니며, 회사는 앱의 기능을 통해 어린이의 개인정보를 의도적으로 수집하는 것을 목적으로 하지 않습니다.

14. 개인정보처리방침 변경

앱 기능, 관련 법령 또는 정책의 변경에 따라 본 개인정보처리방침이 변경될 수 있습니다. 중요한 변경사항이 있는 경우 앱 또는 개인정보처리방침이 게시된 페이지를 통해 안내할 수 있습니다.
